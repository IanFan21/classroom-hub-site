Classroom Hub

Aplikasi web manajemen kelas untuk guru dan siswa SMK — berbahasa Indonesia, tanpa AI di dalam aplikasi.

Classroom Hub membantu guru mengelola kelas, siswa, materi, tugas, kehadiran, kompetensi, dan laporan — semuanya tersimpan di Google Sheets dan Google Drive milik guru yang bersangkutan.

  • Kelas & siswa: data siswa, impor CSV/XLSX, profil siswa.
  • Materi: file dan tautan per kelas, diarsipkan bukan dihapus.
  • Tugas: pembuatan tugas, pengumpulan file siswa, penilaian dan feedback.
  • Kehadiran: rekap dari data absensi resmi, dengan daftar verifikasi untuk data yang meragukan.
  • Laporan & ekspor: kehadiran, nilai, dan pengumpulan dalam format XLSX/CSV/PDF.

Guru masuk dengan akun Google. Siswa masuk dengan memilih kelas, memilih nama, lalu memasukkan token login yang diberikan guru — siswa tidak perlu akun Google.

Kebijakan Privasi

Terakhir diperbarui: 13 November 2026.

Data yang dikumpulkan. Classroom Hub menyimpan data yang dimasukkan guru dan siswa saat memakai aplikasi: nama kelas, nama siswa, materi, tugas, file pengumpulan, nilai, feedback, dan catatan kehadiran. Data ini tersimpan di Google Sheets dan Google Drive milik guru (akun Google guru yang bersangkutan), bukan di server Classroom Hub.

Penggunaan data. Data hanya dipakai untuk keperluan manajemen kelas di atas: menampilkan materi dan tugas, mencatat pengumpulan, menilai, dan membuat laporan. Data tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dipakai untuk iklan.

Akses akun Google. Aplikasi meminta izin akses Google Sheets dan Google Drive semata-mata untuk membaca dan menulis data kelas di akun guru yang bersangkutan. Aplikasi tidak membaca email, kontak, atau file Drive lain di luar folder Classroom Hub.

Penyimpanan dan penghapusan. Data tetap berada di akun Google guru sampai guru menghapusnya sendiri dari Sheets/Drive. Guru dapat menghapus kelas, mengarsipkan materi dan tugas, serta menghapus file pengumpulan kapan saja.

Kontak. Pertanyaan tentang aplikasi dan data ini dapat disampaikan ke pengelola aplikasi melalui email yang tercantum di halaman login guru.
